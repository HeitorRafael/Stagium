# Instruções do Projeto Stagium

## Antes de Começar
1. Instale dependências: `npm install`
2. Configure `.env.local` (copie o existente e preencha as variáveis)
3. Configure o banco: `npm run db:migrate`
4. Popule dados iniciais: `npm run db:seed`
5. Inicie dev: `npm run dev`

## Padrão de Commits
- `feat: descrição` - nova funcionalidade
- `fix: descrição` - correção de bug
- `docs: descrição` - documentação
- `style: descrição` - formatação
- `refactor: descrição` - refatoração
- `chore: descrição` - tarefas auxiliares

## ⚠️ IMPORTANTE - ATUALIZAÇÃO DE PORTFÓLIO
Após CADA commit significativo:
1. Edite `.project.md` → atualizar seção "Última Atualização" e % de Progresso
2. Faça o commit do projeto normalmente
3. Rode `python AgenteMestre/sincronizar_portfolio.py`

## Design System
- **Cores**: Sempre usar CSS variables (`var(--accent-lime)`, `var(--bg-primary)`, etc.)
- **Fontes**: Syne para títulos (`font-family: var(--font-display)`), DM Sans para corpo
- **Dark mode**: Obrigatório em tudo
- **Nunca usar cores hardcoded**

## Regras de Desenvolvimento
- Stack: Next.js 14 App Router + TypeScript
- ORM: Prisma + PostgreSQL
- Auth: NextAuth v5 (Credentials)
- Validação: Zod + React Hook Form
- Estilização: Tailwind + CSS Variables customizadas
- Sempre verificar autenticação server-side nos layouts
- API routes nunca expõem `password` ou `stripeCustomerId`
- Middleware protege `/dashboard`, `/company/*`, `/admin/*`

## Estrutura do Projeto
```
src/app/
├── (auth)/login, register/student, register/company
├── (student)/dashboard, profile, proposals, subscription
├── (company)/dashboard, candidates, vacancies, proposals
├── (admin)/admin/*
└── api/auth, students, companies, institutions, vacancies, proposals
```
