# Stagium

## Info
- **GitHub**: https://github.com/HeitorRafael/Stagium
- **Objetivo**: Plataforma de conexão entre estudantes universitários e empresas que buscam estagiários
- **Stack**: Next.js 14 (App Router) + TypeScript + Tailwind CSS + Prisma + PostgreSQL + NextAuth v5
